# How to keep notes

These are the rules for the AI tool that keeps notes in this folder, Agent Memory. The tool reads this note at the start of every session and follows it. You can change any rule here: the tool follows the note as it is now.

## What goes in

- **A lesson note** each time the person corrects you or you settle something together. Example: "Headings in my case notes follow the prep questions."
- **A topic note** for a person, a course or a project that keeps coming up: what you know about it, in a few lines.
- **The daily note**, `Daily/YYYY-MM-DD.md`, one per day. When you finish a task, add one line to it: what was done and what is still open.

## How to name a note

- Lesson notes: `YYYY-MM-DD-short-title.md`, for example `2026-10-27-headings-follow-questions.md`.
- Topic notes: the name of the topic, for example `Corporate Finance.md`.
- Daily notes: `Daily/YYYY-MM-DD.md`, for example `Daily/2026-10-27.md`.

## How to write a note

- Start with a title line: `#` and the note's name.
- Keep it to a few lines. One fact or one rule per note.
- End with a short "Why:" line that says where it came from, for example "Why: asked for after the Brisa Bikes prep on 2026-10-27."
- Link related notes with `[[note name]]`, for example `[[Corporate Finance]]`.
- Plain words and short sentences.

## When to read

- Before a task, search Agent Memory for the notes related to it (the course, the people, the kind of task) and read them.
- Read `Daily/` only when the person asks about an earlier session.

## Keep it tidy

Do this yourself each time you write a note:

- If a note on the same point already exists, update it instead of writing a new one.
- If two notes say the same thing, merge them into one and point the links at the merged note.
- Fix links that point to no note.
- Never ask the person to fix a note.

## Never

- Never delete a note without asking the person first. That includes the note left over after a merge.
- Never save passwords, logins, keys or any other secret in a note.
- Never change or delete this note unless the person asks.

Save and update notes without asking the person first.
