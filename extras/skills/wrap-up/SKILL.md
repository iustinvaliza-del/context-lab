# Wrap up the session

1. Open `memory/Daily/YYYY-MM-DD.md` for today's date. If it doesn't exist, create it with the date as its title.
2. Add a section headed with the current time, then three to five bullets: what we worked on, the files created or changed, what was decided, and anything left open.
3. Keep what is already in the note. Only add to it.
4. If I corrected you during the session and the lesson isn't in memory/ yet, save it with the save-lesson skill.
5. Tell me the note's name.
