# Save a lesson

1. Say the lesson back in one sentence and check it with me before writing anything.
2. Fix the file it belongs in. A standing rule about me or my work goes in AGENTS.md. A step in how the task is done goes in that task's skill.
3. Save a note in memory/ named `YYYY-MM-DD short-name.md`, using today's date. Write the date, the lesson in one or two sentences, what went wrong, and which file you changed.
4. One note per lesson. If memory/ already has a note on the same thing, update that note instead of adding a second one.
5. Tell me the note's name and the line you changed.
