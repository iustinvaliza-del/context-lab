# Worked examples

One short, invented case per case type, each showing what the prep produces and how the numbers are checked. They are made up for this starter, so they can be shared; real cases stay in `IESE/`, out of git.

| File | Type | What it shows |
|---|---|---|
| `discussion.md` | Discussion | Pre-notes and notes with evidence on both sides, positions left blank |
| `quantitative.md` | Quantitative | A decision tree: Python first, then the workbook and its Checks |
| `data.md` | Data | A regression on a data file, and what the data cannot tell you |
| `optimisation.md` | Optimisation | A linear programme solved in Python, laid out in Excel, checked |
