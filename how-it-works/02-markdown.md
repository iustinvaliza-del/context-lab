# Markdown: what a .md file is and why everything here is one

A markdown file (`.md`) is a plain text file with a few marks for structure:

- `#` at the start of a line makes a heading (`##` a smaller one).
- `-` makes a bullet, `1.` a numbered step.
- `**word**` makes a word bold.

That is most of it. Any text editor opens it (Notepad, TextEdit, VS Code), and Obsidian shows it with the marks rendered.

## Why it is the standard

1. **The model reads it easily.** Headings and bullets show what belongs together, without layout to get in the way. A Word file or a PDF carries formatting the model has to work around.
2. **You can read and change it.** It is plain text. Nothing is hidden, and nothing needs a special program.
3. **Steps become a procedure.** Write the steps of a task once in a file, and the tool follows them every time. That is what a skill is (`04-skills.md`).
4. **Everything in this folder is one.** `AGENTS.md`, the skill, every memory note and every output are markdown files. Learning this one format covers the whole library.

How to say it, using their folder: "Open `AGENTS.md`. It is plain text: a heading with `#`, bullets with `-`. I read it before every session. That is all a markdown file is."
